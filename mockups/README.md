# Helpo mockups (all versions)

Clickable HTML mockups for Educator Helper / Helpo, from v1 to v6. Open `index.html` for the list of versions.

- **v6** (recommended): Nibras, simplified. Two no-scroll teacher screens (`v6/index.html`: Create, then the Lesson workspace with 5 tabs, edit margins and a draggable whiteboard with pencil and eraser) and a single student join-and-play interface (`v6/play.html`). English and Arabic. See `v6/README.md`.
- **v5**: gamified Helpo. Teacher app `v5/index.html`, student app with mini-games `v5/play.html`.
- **v4**: Helpo style taken from the reference screens, with the one-tap student join (`v4/index.html#join`).
- **v3**: kid-friendly, grades 2 to 12, with age bands for students.
- **v2**: school-ready: standards, objectives, levels, mastery.
- **v1**: first redesign after the instructor's feedback.

Each version's `share/` folder holds the PNG images used for review. Design briefs are in `docs/design/`.
Run locally with any static server, for example `npx serve mockups`.
